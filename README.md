# Digital Image Processing Codes
This repository contains a collection of Jupyter Notebook implementations and experiments related to **Digital Image Processing (DIP)** first course.
The notebooks were developed during my studies in the Applied Mathematics program and are intended for educational and practical learning purposes.

---

## Topics Covered in the Notebooks

Some of the implemented concepts include:
* Image reading and visualization
* Grayscale conversion
* Histogram analysis
* Image filtering
* Noise reduction
* Edge detection
* Image enhancement
* Thresholding
* Morphological operations
* Frequency domain processing
---
## libraries Used in the codes
* NumPy
* OpenCV
* Matplotlib
* Scikit-image
---
## Purpose of the Repository
This repository is mainly intended for:
* Learning Digital Image Processing
* Practicing image analysis techniques
* Sharing educational implementations
* Building a reference for future projects

These notebooks are personal educational implementations and may still contain imperfections or experimental code. Improvements and suggestions are always welcome.
